Como rodar agora
Opção 1 — duplo clique no arquivo criado:

codegen.bat
Opção 2 — PowerShell na pasta do projeto:

npm run codegen
Opção 3 — comando direto:

npx playwright codegen --target java --channel chrome https://web.whatsapp.com
Isso abre o Chrome + o painel que gera código Java conforme você clica.
